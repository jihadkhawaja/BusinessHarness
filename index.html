02 / DELIBERATE BOUNDARIES

Useful intelligence.
Explicit control.

AI review belongs inside your engineering process. BusinessHarness keeps its inputs, permissions, and decisions bounded.

Read the security model ↗
[01]

The model reviews. It doesn’t execute.

No shell, filesystem access, or tools for the review provider. Reviewed repository scripts are never run.

[02]

Uncertainty stays visible.

Missing, partial, or unverifiable reference assessments fail the gate. Local findings survive model output.

[03]

Feedback is your choice.

Local reports are the default. Optional GitHub and GitLab feedback checks fresh metadata before publishing.

[04]

Memory starts switched off.

Enable scoped MAGICore memory explicitly. Historical context cannot establish current correctness or approve a change.

A FEW PRACTICAL DETAILS

Before you plug in.

Which AI providers can I use?+

OpenAI’s Responses API and Claude’s Messages API, using compatible structured-output models you configure. You supply your own API credentials. A ChatGPT or Claude app subscription is not used for API access.

Can I connect Jira and other services?+

Yes. Jira tickets, Confluence pages, and Zendesk requests can supply reference context through the configured integration. AgentConnector-backed GET actions and custom JSON APIs extend the available sources. Your pipeline configures credentials and content fields; BusinessHarness retrieves the reference text for review. It does not log in through OAuth, refresh tokens, or enable connector write actions. See reference integrations.

Is on-premises deployment supported?+

BusinessHarness supports execution on organization-managed servers, internal CI agents, and container hosts. GitHub Actions and GitHub App integrations are optional. AI reviews require connectivity to OpenAI or Claude using organization-provided credentials; the offline scan makes no provider, host, or reference API calls. See deployment options.

Does my source code leave my environment?+

The offline scan makes no provider, host, or reference HTTP calls. An AI review sends bounded, redacted diff context, metadata, and resolved references to your selected provider. Redaction is heuristic; review your organization’s data and retention requirements before enabling it.

Can this replace human review or tests?+

No. BusinessHarness supplements code review, tests, SAST, and your existing policy controls. Reference assessments are model judgments about supplied evidence, and some runtime requirements cannot be verified from a diff.
